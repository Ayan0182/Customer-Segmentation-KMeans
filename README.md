# Customer Segmentation using K-Means

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Project Description
This project segments customers into different groups based on their annual income and spending score using K-Means clustering.

## Key Insights
- High income & high spending customers are target customers
- High income & low spending customers need better marketing
- Low income & high spending customers are impulsive buyers
- Low income & low spending customers are low priority
